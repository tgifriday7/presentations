The five breakpoints

Five places an AI program breaks between pilot and scale

Each one shows up early, and each one has a question that detects it.

Breakpoint 1 · Strategic Disconnection

Ten leaders. Ten definitions of success.

Breakpoint 1 · The question
The question that detects it

If you asked ten leaders to describe the primary outcome of this program, separately, in one sentence, would their answers match?

Breakpoint 2 · Incentive Fragmentation

Attendance is not buy-in.

Breakpoint 2 · The question
The question that detects it

If this program succeeds but a given leader’s own metrics do not improve, will that leader still treat it as a priority when it competes with their targets?

Breakpoint 3 · Process Friction

Faster inside a system built to prevent speed.

Breakpoint 3 · The question
The question that detects it

If you mapped how this work really flows today, would the map look like the formal process, or like the workaround your teams built to survive it?

Breakpoint 4 · The Technology Illusion

The tool is live. The work happens the old way around it.

Breakpoint 4 · The question
The question that detects it

If you removed the technology tomorrow, would your teams still agree on how the work should happen?

Breakpoint 5 · Momentum Mirage

The status is green. The steering committee meets less often.

Breakpoint 5 · The question
The question that detects it

What would happen to this program if you stopped actively managing it for ninety days?

The stewardship gap

Sponsors launch change. Stewards keep it alive.

Closing the gap

Four stewardship functions to staff

Interpretation
Translates the enterprise outcome into what success means for each team.
Ownership
Keeps the priority alive under pressure.
Architecture
Covers the seams between functions, where most failures happen.
Reinforcement
Watches for drift, with the authority to intervene before the old way comes back.

It can be one person or four. Each function needs a name next to it, objectives that measure the sustained result instead of the launch, and the authority to act.
